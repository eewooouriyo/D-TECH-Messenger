# D-TECH Messenger

D-TECH Messenger is a modern chat application inspired by classic instant messaging platforms like MSN Messenger. It is designed to make communication simple, fast, and fun for users who want to chat with friends, family, or groups.

## Features

- Send images and view them directly in the chat
- Attach files (beta)
- Use emojis and reactions in conversations
- Create and join group chats
- Simple messaging experience built for everyday communication
- Planned additions include:
  - Calls
  - Voice messages
  - More features in the future

## Why D-TECH Messenger?

D-TECH Messenger aims to combine the familiarity of classic messenger apps with a fresh, customizable experience. It is built to support direct messaging, group conversations, and file sharing in a straightforward interface.

## Project Status

This project is actively being developed, with new features and improvements planned over time.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/eewooouriyo/D-TECH-Messenger.git
   ```
2. Navigate to the project folder:
   ```bash
   cd D-TECH-Messenger
   ```
3. Install dependencies and run the app according to your project setup.
